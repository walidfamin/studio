# **App Name**: FinView

## Core Features:

- Account Overview: Dashboard view of all accounts, displaying balances, credit limits, and recent transactions.
- Spending Charts: Interactive charts visualizing spending habits across different categories (lifestyle, investment, spends).
- Credit Card Tracking: Clear display of credit card limits, current spending, and payment deadlines.
- Income tracking: Income tracker: summary of income across accounts
- User Authentication: User Authentication: Secure user accounts with login/logout functionality.
- Easy Data Entry: Streamlined data entry for transactions, making it easier to add and categorize financial information.

## Style Guidelines:

- Primary color: HSL(210, 65%, 50%) / RGB(33, 150, 243) for trust and stability in financial data representation.
- Background color: HSL(210, 20%, 95%) / RGB(240, 245, 249) provides a clean, light backdrop that ensures data readability.
- Accent color: HSL(180, 55%, 45%) / RGB(45, 190, 185) to highlight key metrics and interactive elements with a touch of freshness.
- Body font: 'PT Sans' (sans-serif) for a modern, readable feel.
- Headline font: 'Space Grotesk' (sans-serif) complements 'PT Sans,' used for impact in charts.
- Use minimalist, clear icons to represent transaction types and categories for easy identification.
- Implement a card-based layout to organize financial information and charts in a visually appealing manner.
